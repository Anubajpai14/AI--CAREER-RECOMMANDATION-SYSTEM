AI Career Recommendation System

An AI-powered career guidance web application that recommends suitable career paths based on a student's education, skills, interests, and experience.

Features

- Personalized career recommendations
- Alternative career options
- Missing skills suggestions
- Step-by-step learning roadmap
- Responsive dark-themed user interface

Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Google Gemini API

Setup Instructions

1. Clone or download this repository.
2. Install dependencies:
   "npm install"
3. Create a ".env" file in the project root.
4. Add your Gemini API key:
   "GEMINI_API_KEY=your_api_key_here"
5. Start the backend using:
   "node server.js"
6. Open "index.html" using Live Server.

Security

Keep your API key private. Never upload your ".env" file to GitHub.
